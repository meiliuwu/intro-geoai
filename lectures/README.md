# Lectures

Each lecture is two hours of short, visual input and group activity. Slides favour figures and diagrams over text, and every lecture includes a student-led paper clinic, a signature group activity and an "ethics minute". See the [teaching approach](../course-info/teaching-approach.md) for the formats.
