# Week 6 Lab · Generative maps

**Status:** in preparation. Lecture: [AI and cartography](../../lectures/week06-ai-and-cartography/)

## Planned outline

1. Run [pix2pix](https://github.com/junyanz/pytorch-CycleGAN-and-pix2pix) with the pretrained *sat2map* and *map2sat* models.
2. Evaluate generated map tiles numerically (agreement on road, water and building colours) and by eye.
3. Ask an AI assistant to write code for a choropleth of the Week 5 greenery results; critique and fix it with a cartographic checklist.
4. Train a small CNN to tell real map tiles from generated ones.

**Stretch:** train pix2pix for a few epochs on the *maps* dataset using the repository's Colab notebook.
